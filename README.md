Task 5: Capture and Analyze Network Traffic Using Wireshark

Objective

To understand network traffic and identify different network protocols.

Tools Used

- Python
- Pydroid 3
- Wireshark (for real packet capture)

Description

This project demonstrates basic network traffic analysis using Python. It displays sample packet details, including source IP address, destination IP address, port number, and protocol name.

Protocols Identified

- TCP
- UDP
- DNS
- HTTP

Working

1. Import the required Python modules.
2. Create sample network packet data.
3. Display packet details.
4. Count the number of packets for each protocol.
5. Print the final analysis summary.

Output

The program displays packet details and the count of each protocol. It finishes with the message "Analysis completed successfully!"

Result

Basic network traffic analysis was demonstrated successfully using Python.

Note: This Python program uses sample data for demonstration. Actual network packet capture and ".pcap" file export must be performed using Wireshark.

Conclusion

This task helps to understand basic network protocols and packet analysis concepts.
